WHY deriv_client.py IS REPLACED
-------------------------------
The existing 1,000-tick paging fix is preserved, but v1.2 keeps one WebSocket
open for all pages of a symbol's 25,000-tick history request. This materially
reduces connection overhead in multi-symbol studies.

FIRST RUN
---------
After Render deploys:

1. Open "Cross-Market & Stability".
2. The market list is populated from Deriv active_symbols dynamically.
3. Select about 5 Volatility / Synthetic markets.
4. Ticks per market: 25,000.
5. Reference quote stake: $1.00.
6. Leave "Archive reference proposal prices" checked.
7. Run the frozen batch study.

The statistical settings are intentionally NOT editable:
- Discovery: 70%
- Min context N: 150
- Min discovery uplift: 0.75 pp
- FDR q: 0.10
- Shrinkage: 200
- Rolling window: 5,000 ticks

WHAT v1.2 REPORTS
-----------------
Per market:
- tests run
- discovery candidates
- validated holdout candidates
- number of 5,000-tick windows
- effects recurring in >=2 windows
- recurrence of validated candidates across recent v1.2 runs

Across the current batch:
- the same validated condition recurring on >=2 different symbols

PRICING ARCHIVE
---------------
The web batch archives a compact six-contract reference grid:
- Match 0
- Match 5
- Over 4
- Under 5
- Even
- Odd

It stores ask price, payout, break-even probability and timestamp in the
existing ProposalSnapshot model using decision="ARCHIVE V1.2".

For one manual archive round on Render shell:
python manage.py archive_digit_quotes --symbols 1HZ100V --stake 1

For a continuous paid Render background worker, for example every 5 minutes:
python manage.py archive_digit_quotes --symbols 1HZ100V --stake 1 --interval 300

Or let the command discover up to 5 currently active synthetic markets:
python manage.py archive_digit_quotes --stake 1 --interval 300 --limit-symbols 5

Do NOT run a continuous collector on a free sleeping web service.

SAFETY / INTERPRETATION
-----------------------
Rolling recurrence is diagnostic, not a trading signal.
Cross-symbol recurrence is stronger evidence but still not proof.
No real-money execution is added or enabled by v1.2.
No Martingale, loss chasing, or stake escalation is introduced.
