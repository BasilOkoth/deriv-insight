IMPORTANT

DEPLOY
------
Upload the six files above to the same paths in GitHub and commit to main.
Render should auto-deploy.

After deployment:
1. Sign in.
2. Open "Conditional Edge Lab".
3. Use the same symbol you tested in Digit Laboratory.
4. Start with:
   Ticks: 25,000
   Discovery sample: 70%
   Min discovery observations: 150
   Min discovery uplift: 0.75 pp
   FDR q threshold: 0.10
   Live quote stake: $1
   Max live quotes: 8
5. Click "Run conditional study".

HOW TO READ IT
--------------
Discovery candidates:
Patterns found only in the older part of the data after false-discovery-rate
correction.

Validated:
Discovery-frozen patterns that also retain a positive effect and pass the FDR
threshold in the newer holdout data.

Live-price candidate:
A holdout-validated pattern whose shrinkage-adjusted holdout probability beats
the current Deriv break-even probability AND whose raw 95% lower confidence
bound also beats break-even.

WATCH:
The shrunk model probability beats current break-even, but the 95% lower bound
does not. This is not strong enough for demo execution.

NO LIVE EDGE:
The validated historical pattern does not beat the current Deriv proposal
price.

This page NEVER executes a trade.
