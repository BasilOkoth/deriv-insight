DERIV INSIGHT v1.2.3 — STEPWISE BALANCED BATCH FIX
===================================================

This fixes the Internal Server Error caused by running all 8 x 25,000-tick
balanced studies inside one Gunicorn web request.

REPLACE these COMPLETE files:
1. research/views.py
2. research/urls.py
3. research/services/balanced.py
4. research/templates/research/balanced.html

Everything else from v1.2.2 / v1.2.1 stays unchanged.

No database migration is required.
No new Render service, Redis, Celery, worker, or environment variable is
required.
Do NOT increase Gunicorn's 120-second timeout for this fix.

HOW THE FIX WORKS
-----------------
Old v1.2.2:
One browser POST tried to run all selected markets before returning HTML.
Eight 25,000-tick markets could exceed Gunicorn --timeout 120.

New v1.2.3:
1. "Run all balanced studies" immediately creates a saved batch.
2. Every selected market is stored as PENDING in ResearchRun.
3. Browser is redirected to the saved batch page.
4. JavaScript calls a new endpoint:
     /balanced/batch/<batch_id>/step/
5. That endpoint processes EXACTLY ONE pending market.
6. Result is stored COMPLETE or FAILED.
7. Browser calls the endpoint again for the next market.
8. When PENDING reaches zero, the page reloads and shows the final comparison.

Therefore:
- 8 markets are no longer one 120-second request.
- one market = one web request;
- refresh does not lose completed results;
- leaving the page does not delete the batch;
- reopening the batch continues pending markets;
- failures can be retried without rerunning completed markets.

AFTER DEPLOYMENT
----------------
1. Open Balanced Contracts Lab.
2. Keep all eight 1-second Volatility markets selected.
3. Ticks per market = 25,000.
4. Stake = $1.
5. Click "Run all balanced studies".
6. You should immediately see the batch page with PENDING rows.
7. The progress message should move market-by-market:
     Completed 0 of 8
     Completed 1 of 8
     Completed 2 of 8
     ...
8. When complete, the final comparison table appears.
9. If a symbol still fails after API retry/backoff, use "Retry failed markets".
